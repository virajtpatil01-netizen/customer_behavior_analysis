# Data Analytics Project

## Overview
This project demonstrates the complete workflow of a Data Analytics project, starting from data collection and cleaning to dashboard creation and reporting. The project focuses on extracting meaningful insights from raw data using Python, SQL, and Power BI.

### The workflow includes:
- Loading and analyzing datasets in Python
- Performing Exploratory Data Analysis (EDA)
- Cleaning and transforming data
- Running SQL queries using PostgreSQL Server
- Creating an interactive Power BI dashboard
- Building a project report
- Preparing a presentation using Gamma

---

## Dataset
The dataset used in this project contains structured business/customer/sales-related data for analysis purposes.

### Dataset Features
- Customer Information
- Product Details
- Sales & Revenue Data
- Purchase Behavior
- Ratings & Reviews
- Category-wise Insights

## Project Steps

### 1. Data Loading
- Imported dataset using Python
- Loaded CSV/Excel data into Pandas DataFrame
- Connected database using SQL

### 2. Exploratory Data Analysis (EDA)
- Checked dataset structure
- Identified missing values
- Performed statistical analysis
- Created visualizations for trends and patterns

### 3. Data Cleaning
- Removed duplicates
- Handled null values
- Fixed data types
- Standardized column names
- Treated outliers where necessary

### 4. SQL Analysis
Performed analytical SQL queries such as:
- Total revenue analysis
- Customer segmentation
- Category-wise sales
- Average ratings
- Top-performing products
- Monthly sales trends

### Supported Databases
- PostgreSQL

### 5. Dashboard Creation
Built an interactive Power BI dashboard including:
- KPI Cards
- Sales Trends
- Revenue Analysis
- Customer Insights
- Product Performance
- Filters & Slicers

### 6. Report & Presentation
- Created a detailed analytics report
- Designed presentation slides using Gamma
- Summarized business insights and recommendations

## How to Run the Project

### 1. Clone the Repository
```bash
git clone <repository-link>
```

### 2. Install Required Libraries
```bash
pip install pandas numpy matplotlib seaborn sqlalchemy
```

### 3. Run Jupyter Notebook
```bash
jupyter notebook
```

### 4. Execute SQL Queries
- Import dataset into PostgreSQL Server
- Run provided SQL scripts

### 5. Open Power BI Dashboard
- Open `.pbix` file in Power BI Desktop

### 6. View Report & Presentation
- Open the project report
- Review Gamma presentation slides
